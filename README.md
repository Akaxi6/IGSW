# IGSW

Project website for **IGSW: Multi-Weather Urban Scene Reconstruction with Intrinsic-Decoupled Gaussian Splatting**.

**Website:** https://akaxi6.github.io/IGSW/

The site presents the framework, visual comparisons, full-sequence videos, quantitative results, ablations, and the accompanying manuscript PDF.

## Deployment

This is a static website. GitHub Pages serves `index.html` from the `main` branch at the repository root. Images, videos, and the PDF use relative links and do not require a build step or a CDN.

To preview locally, open `index.html` in a browser. To update the site, replace the relevant webpage or media files and commit to `main`.
